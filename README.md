# فالو‌بک‌چکر گیت‌هاب

یک ابزار سبک و بدون نیاز به بک‌اند برای مقایسه‌ی حساب‌هایی که در GitHub دنبال می‌کنید با دنبال‌کننده‌هایتان.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید یا آن را با هر وب‌سرور استاتیک سرو کنید. پروژه هیچ وابستگی یا فرایند build ندارد.

## امکانات

- دریافت کامل لیست followers و following با صفحه‌بندی ۱۰۰تایی
- نمایش تعداد ارتباط‌های دوطرفه، دنبال‌کننده‌ها و فالو‌بک‌نشده‌ها
- جست‌وجو و مرتب‌سازی فهرست
- بازکردن مستقیم پروفایل هر حساب
- خروجی CSV و JSON
- پشتیبانی اختیاری از Personal Access Token برای عبور از محدودیت API عمومی

## نکات حریم خصوصی

اطلاعات مستقیماً از API عمومی GitHub در مرورگر خوانده می‌شود و در این پروژه ذخیره نمی‌شود. اگر توکن وارد کنید، فقط برای همان درخواست‌های مرورگر استفاده می‌شود.

برای استفاده‌ی امن، توکن را با دسترسی‌های حداقلی بسازید و پس از استفاده آن را revoke کنید. برای حساب‌های عمومی معمولاً به توکن نیاز نیست.

## محدودیت

GitHub روی درخواست‌های بدون احراز هویت محدودیت نرخ دارد. اگر خطای ۴۰۳ گرفتید، کمی صبر کنید یا یک توکن کم‌دسترسی وارد کنید.
